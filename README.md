# Dream Snatch

A simple Electron-based screenshot utility. Invoke the tool using **Ctrl+Shift+S** (or **Cmd+Shift+S** on macOS) to capture your screen, crop the screenshot, and apply aesthetics like border radius, shadow, and a custom background.

## Setup

```bash
npm install
npm start
```

After launching, use the shortcut to capture a screenshot. You can then tweak the captured image and download it.
